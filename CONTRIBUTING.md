# Contributing to Flowbound

Use Node.js 22.18 or newer, then run `npm ci` and `npm run build`. Try your change in a new directory using a packed copy as shown in the [README](README.md).

Describe what your pull request changes for users and how you checked it. Run `npm run lint`, `npm run types` and the affected tests with `node --test test/<file>.test.ts`. Use made-up data and test providers in examples.

Report security problems through [private vulnerability reporting](SECURITY.md).
